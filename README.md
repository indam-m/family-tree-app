# Family Tree

A web application for visualizing and managing family tree data, built with [Next.js](https://nextjs.org).

## 🚀 Overview

This project allows users to view, search, and edit family relationships in an interactive tree format. It leverages modern React features and Next.js for fast, scalable development.

## 🛠️ Technologies

- **Next.js 15**: React framework for server-side rendering and static site generation.
- **TypeScript**: Type-safe development.
- **Tailwind CSS**: Utility-first CSS framework.
- **GraphQL**: For querying and mutating family tree data to family tree service.

## 📁 Project Structure

- `src/` — Main source code (components, pages, hooks, etc.)
- `public/` — Static assets
- `README.md` — Project documentation

## ⚡ Getting Started

1. **Install dependencies**

   ```sh
   npm install
   # or
   yarn install
   ```

2. **Run the development server**

   ```sh
   npm run dev
   # or
   yarn dev
   ```

3. **Open your browser**
   Visit [http://localhost:3000](http://localhost:3000) to view the app.

## 📝 Customization

- Edit pages in `src/app/` or `src/pages/`.
- Add or modify components in `src/components/`.
- Update styles in `src/styles/` or using Tailwind classes.
